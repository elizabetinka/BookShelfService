# Лабораторная №1

## Задача

Создать программу для учета библиотеки с книгами (BookShelf)
Приложение должно предоставлять возможности:
- Добавить новую книгу в библиотеку
- Удалить книгу по ее ID
- Посмотреть список книг
- Искать книги по критерию


### Ключевые моменты

- Модель ввода/вывода остается на усмотрение (например, консоль)
- Реализация должна использовать ключевые сущности Swift и чистую архитектуру (struct, classes, enum, protocol, optionals и тд)

### Требования

Структура книги, как минимум, должна содержать:
- id (уникальный ID книги, например, UUID)
- title (название книги)
- author (автор книги)
- publicationYear (год издания, может отсутствовать)
- genre (жанр книги, .fiction, .nonFiction, .mystery, .sciFi, .biography и т.д)

Обязательно нужно закрыть все публичные интерфейсы за протоколами и использовать их в реализации (protocol-oriented programming)

С приложением можно взаимодействовать больше одного раза, выбирая нужную функцию из перечисленных. Желательно, также, иметь функцию выхода из приложения.

## Дополнительно

- Добавить поддержку разных предметов хранения (комиксы, у которых будет еще номер выпуска; учебники с фильтрацией по номеру курса и тд)
- Добавить красивую обработку ошибок через свою сущность с ошибками (реализация протокола `Error`, можно через `enum LibraryError: Error {...}`)
